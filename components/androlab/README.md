AndroLab backend from dineshshetty/Android-InsecureBankv2, under the included MIT license.

Adapted to Python 3, loopback-only listening and no form/user/password console output. Training behavior is preserved. This is the real upstream backend, not a replay fixture. Original commit and digests are recorded in upstream.json.

Prepare locally with `python3 scripts/prepare_androlab.py`. The original demo database is downloaded and checksum-verified; an existing database is never overwritten.
